# .files - my *personalised* NixOS config

this repo is my entire configuration for my linux system.
includes:
- Apps
- System servives
- Dotfiles
- Global configs "E.G. /etc"

this flake has three flake profiles
- nixos-x86: a full config on x86 arch
- nixos-arm-parallels: a full config on aarch64 arch (Parallels VM on macOS)
- nixos-orbstack: a minimal config for orbstack "linux machines on macos, like WSL"
